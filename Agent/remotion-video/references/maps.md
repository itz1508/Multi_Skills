# Remotion Maps

For static maps, animated routes, markers, and geographic explainers.

## Techniques

- **Static map**: Screenshot or rendered map image with animated overlays
- **MapLibre**: Vector tiles with animated camera and markers
- **MapTiler**: Full-featured vector maps with custom styling
- **Mapbox**: Premium vector maps with terrain and satellite layers

## Key Patterns

- Animate camera position with `interpolate`
- Use GeoJSON for routes and shapes
- Markers should have entrance animations
- Pre-render map tiles for performance
